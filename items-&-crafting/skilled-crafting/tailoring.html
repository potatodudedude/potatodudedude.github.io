Tailoring

General Overview and Rules

How to tailor clothes

  1. Choose which type of clothing you want to create below.
  2. Go down the list of customisations for that piece. You must choose 1 and only 1 option for each customisation.
  3. Add the modifiers from the customisations to the base stats.
  4. Spend resources to create the clothing during rests.

Requirements

To do anything below, you require the tailoring skill, alongside a set of tailoring tools. Customisations will have specific tailoring skill requirements.

Customisation stat interactions

  • Skill bonuses provided by clothes can allow skills to go over the usual cap of 3.
  • Clothes have a stat called "quality", alongside certain stats called "XX per quality". Multiply these together to get the final stat modifier.

Clothing cost calculations

Each clothing's final cost is derived as such:
(Total Cost of Material) x (Time-units taken x 0.50) x (Customisation Modifier)

Repairing Clothes

Repairing a damaged piece of clothing takes half the resources and time it took to make it. The same skill and tool requirements apply.

Clothes:

These go under your armour.

Travelling Clothes:

Base Stats:

Quality: 2
Weight: 0kg
Material Cost: 2 fabric units
Craft Time: 2 time-units

Customisation - Material:

  • Medium Grade Fabric (Skill 2)
    • Standard material, no effects.
  • Low Grade Fabric (Skill 1)
    • -1 high class mannerisms skill.
    • -1 quality.
    • -50% time-unit cost.
  • High Grade Fabric (Skill 3)
    • -1 low class mannerisms skill.
    • +1 quality.
    • +50% time-unit cost.

Customisation - Breathability:

  • Standard (Skill 1)
    • Standard breathability, no effects.
  • Extra Breathable (Skill 2)
    • +2 to hyperthermia saving throws per quality.
    • +50% time-unit cost.
  • Extra Un-breathable (Skill 2)
    • +1 to hypothermia saving throws per quality.
    • +50% time-unit cost.

Customisation - Decoration:

  • Standard (Skill 1)
    • Standard decoration, no effect.
  • Burgher (Skill 2)
    • +1 low class mannerisms skill per quality.
    • +50% time-unit cost.
    • +100% material cost.
  • Regal (Skill 3)
    • +1 high class mannerisms skill per quality.
    • -1 low class mannerisms skill per quality.
    • +50% time-unit cost.
    • +100% material cost.
